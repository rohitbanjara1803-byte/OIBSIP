# Retail Sales EDA Analysis

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of a retail sales dataset. The objective is to analyze sales data, identify patterns and trends, and gain useful business insights through data analysis and visualization.

## Objectives

- Understand the retail sales dataset
- Perform data cleaning and preprocessing
- Explore sales trends and patterns
- Analyze important sales-related variables
- Create visualizations to understand the data
- Generate meaningful business insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The project uses a retail sales dataset containing information related to retail transactions and sales.

## Project File

- `Retail_Sales_EDA.ipynb` - Jupyter Notebook containing the complete analysis
- `retail_sales_dataset.xls` - Dataset used for the analysis

## Analysis Performed

The analysis includes:

- Data loading and inspection
- Data cleaning
- Descriptive statistics
- Exploratory data analysis
- Data visualization
- Identification of trends and patterns
- Business insights

## Conclusion

The analysis provides insights into retail sales patterns and helps in understanding the key factors affecting sales performance.
